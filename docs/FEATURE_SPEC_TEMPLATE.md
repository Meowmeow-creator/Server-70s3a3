# 功能说明模板

- 功能/问题：
- 分支与 base commit：
- 负责人/集成人：
- 玩家触发与预期变化：
- 修改文件与共享区协调：
- 当前国服来源、原文件/方法与 SHA256：
- 跨版本资料用途及不确定点：
- 等级/前置/难度/入口/每日限制：
- 房间/NPC/怪物/AI/领主：
- 掉落/拾取/材料扣量/奖励公式：
- 请求/回包命令及字段、失败分支：
- 事务、收据、容量、保存/旧档恢复：
- 可丢弃存档及独立端口：
- 新测试与复用证明（版本/哈希/范围）：
- 满包、重复、异常中断、保存重登结果：
- 原完整收包验证与模型边界：
- 玩家实测结果或明确待验收：
- 已知未完成、风险及回滚办法：

状态只能写：研究中 / 内部验证 / 玩家验收待测 / 已验收。奖励入账不等于 UI、AI、战斗效果都已验收。
