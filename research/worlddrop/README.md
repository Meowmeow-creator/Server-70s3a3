# 世界掉落表接入草稿 FG182

用户反馈生锈的铁片、硬化剂等通用物品不掉落。本草稿从 FG175 的145份稳定源显式复制构建146源，补上当前国服 `etc/worlddrop.etc` 分支，保留已有金币、怪物专属、任务和随机池掉落。未合并 main，未部署玩家入口，`releaseAllowed=false`。

## 范围与数据

当前 PVF SHA256：`61ccc511c0b3804741387344dc6862c3d6731aad3d4334142a35e095141aae0d`。导出99个等级档，9108条含零权重记录，去重为24个完整配置；87种正权重物品包括材料、药剂、制作图、徽章和副职业材料。

生锈的铁片是3027，最下级硬化剂是3151；3028皮革、3030碎布、3142碎骨、3156砥石也在表内。3152至3155等更高级硬化剂没有本表直接掉落，不擅自增加。3108是黏糊糊的触须，不能当作铁片。

两份侧表仅供研究构建：完整世界权重及87项最小物品元数据。基础目录已有的23项保持原定义，补64项缺失定义。29种徽章仍是可堆叠材料；制作图和药剂按消耗品库存类别保存。新增定义未实现的使用或制作效果会被现有服务拒绝，不扣物品。13项明确上限1000、29项徽章上限100；其余45项原文件没有写上限，使用现有服务保守1000上限，不能称为已证明的原版默认值。

## 原证据与适配边界

当前国服表数据配合参考台服原生 `089022BE` 导入、`085383B8` 世界选择器、`085334A4` 随机入口进行验证。原导入器保留零权重并将首字段替换为总权重。原抽取先取0至100000（含端点）；中签条件是小于等于总权重，随后取0至总权重（含端点），以严格小于累计权重选物品。CDF等于总权重时不掉物品，不重抽、不改权重。不能把权重直接写成百分比。

本草稿仅普通单人、非领主、一次、中性100掉落倍率；按服务已有收据随机源选择，重复死亡不重抽。参考外层 `_MakeDropItems` 的队伍/死亡原因分支还依赖原服务参数。当前国服资料缺少该参数，完整国服外层调用条件尚未独立恢复；队伍、活动、战争区域等路径未实现。真实请求验证使用当前 ownerFFFF、零参与者格式，对应参考外层无该分支时的一次调用。没有声称完整还原所有模式的掉落触发器或原MT随机序列。

9002份固定输入/输出来自完整原生导入及选择函数执行，包含99档CDF边界、概率阈值、零权重和未配置等级；不从新C#实现反推期望。原生执行中的解析字符串、容器分配、随机端点、物品工厂和UI等端点为模型，不能视为真人效果。
